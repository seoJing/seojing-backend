## Implementation

- `python/jev_reader.py`: one job/document per worker, chronological prefix invariants, up to eight automatic questions and one creation per unit; role and comparative-improvement basis only. Trigger heads receive the generated job conditions. Answer checks receive the prepared sufficient/insufficient conditions; role completion and adopted-proof auditing additionally enforce the same concrete-personal-task boundary so compound duties cannot silently become a requirement to perform every advertised duty. Basis completion retains the prepared conditions.
- `python/jev_grounded.py` / `atomic_decisions.py`: optional explicit question-origin index allows supporting text before the question without reordering or omitting the raw prefix. Default-origin experimental inputs are unchanged.
- `python/jev_runtime.py` / `jev.ts`: ephemeral bounded JSONL worker; secret through stdin only, isolated environment, fixed HTTPS provider, no redirects or retries, cancellation/deadlines, strict source/schema checks and usage counters. No model/source logs or Laya fallback. Defaults: 600 Jev requests and 2M input tokens per document; token limit is checked between requests, so a final request can cross it. A budget failure terminates rather than presenting a complete report.
- `jev-pipeline.ts`: internal full reader/report runner using the existing validated semantic state transitions. New verified proof replaces previously adopted proof so subsequent withdrawals audit the current answer.
- `tools/jev-flow-eval.ts`: explicit synthetic-only live runner with source hashes, parsed source, real generated criteria, events, report and timings. It does not exercise HTTP serving, browser interaction, concurrent users or deployment.

Sequential Jev coverage is limited; method/result and other matters are reviewed by Codex at the end. Confidence thresholds are not calibrated accuracy. A missing note does not mean the source is complete, deficient, or fully reviewed. More than six source units cannot be squeezed into an event by silently dropping proof.
