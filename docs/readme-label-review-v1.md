# Laya 기준 사례 30개 · 사람 검수지

아직 검수되지 않은 합성 개발 사례다. 검수자 이름·선택·근거를 빈칸으로 두었다. 모델의 임시 라벨은 이 문서에 표시하지 않는다. 사람 검수 완료로 자동 등록하거나 학습에 넣는 기능은 없다.
