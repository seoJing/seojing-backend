# README Lab 배포 전 보안 검증 · 2026-10-05

대상은 초대 코드로 제한하는 지인용 Jev + Codex Lab이다. 인터넷 전체 공개, 일반화된 판단 정확도, 침투 테스트 완료 또는 취약점 부재를 의미하지 않는다. 실제 운영 반영 결과는 협업 보드 OPS-01의 최종 게시글에서 별도로 확인한다.

## 확인 및 수정

- 초대 코드와 명시적 `readme-jev-v1` 동의가 있어야 세션을 발급한다. 다른 세션은 같은 초대 코드를 사용해도 원문·작업 조회/취소 권한이 없다. 입력 해시가 달라진 분석 시작은 거부한다.
- 요청/응답 크기, 파일 확장량, 파서 시간·메모리, 모델 호출·출력·시간, 직렬 큐와 초대별 일일 3회 제한을 유지한다. 로그인 제한은 프록시 뒤에서 공유될 수 있는 10회/분 한도다. 임의 전달 헤더를 신뢰하도록 변경하지 않았다.
- 실제 라우트에 합성 입력을 넣은 검사에서 인증 실패 401, 다른 세션 404, 변경 해시 409, 무동의 400, 취소 204를 확인했다. 요청 로그에 초대 코드·Bearer·원문 본문이 포함되지 않았다.
- 모델 환경 변수는 허용 목록만 전달한다. Codex는 사용자 설정/도구/검색을 비활성화한 임시 읽기 전용 실행이다. 원문과 리포트는 인증된 세션에만 반환하며 데이터베이스에 저장하지 않는다. 파싱은 제한된 Worker thread로 수행하며 OS 프로세스 샌드박스라고 표현하지 않는다.
- SIGTERM을 무시하는 하위 프로세스가 부모 종료 뒤 남는 문제를 수정했다. 모델 그룹 추적과 전용 launcher의 SIGTERM/SIGINT 처리로 새 실행을 거부하고 강제 종료 유예가 끝난 뒤 서버를 종료한다. 실제 프로세스 2개 회귀 테스트를 추가했다. SIGKILL·호스트 장애 시 정리를 보장하지 않는다.
- 전용 launcher는 소유자 전용 권한의 외부 설정 파일만 허용한다. Jev 키/초대 코드가 Git, plist의 Lab 값, 인수, 공유 로그에 들어가지 않도록 한다. 임시 모델 디렉터리도 전용 0700 경로를 사용한다. 기존 운영 환경과 이전 릴리스를 별도로 보존한다.
- 프런트 원문·리포트·메모의 악성 HTML 검사는 텍스트 렌더링을 확인했다. 프록시는 허용된 경로/메서드/쿼리만 전달하고 리다이렉트·불필요한 헤더를 차단한다. 원문은 브라우저 영구 저장소에 저장하지 않는다.

## 의존성

Fastify 5.12.5, Swagger UI 6.1.1, static 10.1.5, find-my-way 9.9.0, fast-uri 3.1.8 등 수정 버전을 적용했다. 최종 `pnpm audit --prod`의 남은 1건은 Prisma CLI 설정 경로의 deepmerge-ts 7.1.5다. [관리자 권고문](https://github.com/RebeccaStevens/deepmerge-ts/security/advisories/GHSA-ggr8-5vv4-36mx)은 같은 위치의 순환 객체 그래프가 필요하며 일반 JSON에는 적용되지 않는다고 명시한다. 실제 PrismaClient 초기화에서 이 모듈을 로드하지 않았고 README 요청 경로의 사용도 발견하지 못했다. 검증 없이 Prisma 주요 버전을 바꾸거나 예외를 전체 안전 판정으로 확대하지 않는다.

프런트는 React/DOM/RSC 19.2.8을 함께 적용했다. [RSC 서비스 거부 권고문](https://github.com/react/react/security/advisories/GHSA-wx67-qw84-cm4g)에 해당하는 디코더가 실제 Worker 번들에 있었으므로 배포 전에 수정했다. 독립 검토에서 새 번들의 수정 디코더와 구형 fallback 부재를 확인했다. 나머지 프런트 audit의 빌드 도구 항목을 모두 제거했다고 주장하지 않는다.

## 검증 기록

- TypeScript 227 통과, 기존 DB 의존 6개 생략. Python 기존 venv에서 101 통과. lint/typecheck/build/format 통과.
- 전역 Python은 실험 테스트에 필요한 torch가 없어 실패했고 기존 학습용 venv로 전체 테스트를 다시 통과했다. Jev 운영 런타임에는 torch가 필요 없다.
- 합성 문서의 컴파일된 loopback HTTP 전체 흐름: 공고 준비 82.404초, 전체 194.929초, 리포트 7개. 최초 검사 도구의 빈 JSON DELETE 요청 400을 수정하고 재실행했다. 이 측정은 최종 종료 처리 보강 전이며 모델 판단 소스는 같다. 최종 실제 배포/브라우저 검증은 별도 필요하다.
- 독립 프런트 검증: 프록시 40개, 페이지 4개, DOM 주입 검사 통과. 보안 패치 lint/format/coverage/smoke/build/내용 fallback/public readback 통과. Worker gzip 2081.61 KiB.

합성 산출물과 검사 로그는 `.local/readme-laya/deploy-*`, `.local/readme-lab-production/loopback-smoke-v2/`에 보관한다. 이 경로의 보호된 자격 증명 파일은 문서·게시판에 복사하지 않는다. 일반 사용자 원문을 테스트 증거로 사용하지 않는다.
